# OpenSapphire for VSCode

OpenSapphire 前端语言的官方 VSCode 扩展。

## 功能

- 🎨 **语法高亮** — `.os` 文件的关键字、元素、事件、样式、字符串、注释
- 💡 **智能补全** — 所有内置元素与事件指令，带代码片段
- 📖 **悬停文档** — 鼠标停在 `st1` / `botton` / `addhttp` 上就能看到用法
- ▶️ **一键编译** — 标题栏 ▶ 按钮或 `Ctrl+Alt+R` 编译当前文件
- 🌐 **自动打开** — 编译成功后自动用浏览器打开 `dist/xxx.html`

## 安装

### 从 VSIX 安装

```bash
code --install-extension opensapphire-vscode-1.0.0.vsix
